Standalone Auditor Binary Packaging (Nuitka)

Create a compact, zero-dependency Windows .exe for rapid endpoint deployment.

1-Click Compilation Command

Run from the repository root to compile a standalone executable:

uv run nuitka --standalone --onefile --assume-yes-for-downloads --output-filename=q_scan.exe tools/q_scan/q_scan.py

Endpoint Auditor Package Layout

Copy these 2 files onto a USB drive or target endpoint:

  • q_scan.exe (Compiled standalone scanner executable)
  • config.json (Target roots, keywords, extensions, exclusions)

Execution & Output

Double-click q_scan.exe or run via PowerShell. It will stream matches live to scan_results.csv with zero buffering. Once done, upload the CSV above!
